# Changelog

## 0.1.0

- Initial Android release.
- Native AGSL liquid-glass rendering with version fallbacks.
- Refraction, blur, tint, depth, borders, dispersion, glare, and grain.
- Native press and elastic drag interaction.
- Configurable `interactive` touch ownership for composed controls.
- Accessible `LiquidGlassButton` built on React Native Pressable semantics.
- Dependency-free Android system Photo Picker helper.
- React Native New Architecture Codegen and Android autolinking.
